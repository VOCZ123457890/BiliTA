# BiliTA · BiliBiliToyAi

> 仓库名 **BiliTA**（原 BiliaiDebugV / GLM-BDV）｜ 全称 **BiliBiliToyAi** ｜ MIT
>
> 一个跑在**哔哩哔哩 TOY** 里的免费 AI 对话应用。前端直连智谱 GLM，用户不用注册、不用填 Key，打开就能聊。
> 当前版本 **v3.7.0** · 直连优先 + 静默降级 · 季节主题 · 多会话 · 圆桌讨论 · 创作四件套 · 发图看图 · [MIT License](./LICENSE)
>
> **连接架构（v3.5.0）**：B站 App 内的 WebView 关闭了同源检查，可**纯直连**智谱，不经过任何服务器；
> 在普通浏览器里打开时，直连会被 CORS 拦截，程序会**静默切换到中转地址**（`CONFIG.RELAY`），用户无感知。
> 两种环境都可用，且界面状态栏会如实显示当前通道（直连智谱 / 中转 / 演示模式）。

> ⚠️ **仓库版已清空内置 API Key**（`CONFIG.API_KEY` 为空字符串）。
> 想让线上实例可用，请填自己的智谱 Key，或用「设置 → 我的 API Key」让用户自带。
> 公开仓库里绝对不要提交真实 Key —— 一旦推到 GitHub，额度当天就会被爬虫刷完。

## ⚠️ 必读：直连的两个事实

1. **「去掉 -Flash」≠ 免费。** GLM-5.3 是旗舰付费档（输入 8 元/M、输出 28 元/M），
   比 GLM-5.3-Flash（0.8 / 2.8 元）还贵 10 倍。真正 0 元的是
   `glm-4.7-flash`、`glm-4-flash-250414`、`glm-4.5-flash` 这三个 Flash 档。
   本项目「对用户免费」指的是用户不花钱、额度由作者账户垫付。
2. **浏览器直连会被 CORS 拦截。** 智谱接口不返回 `Access-Control-Allow-Origin`
   预检头，网页 `fetch` 直连在标准浏览器环境会被拦（已实测）。本项目已按
   「直连优先」实现：直连失败时给出明确诊断，并在**隐藏入口 → 旧版引擎**里保留
   v1 中转兜底，填入你自己的 Worker 地址即可切回（`worker.js` 仍保留在文件夹里，属旧版遗留件）。

## 三步上线

1. **填 Key**：编辑 `index.html` 顶部
   ```js
   API_KEY: '你的智谱Key',          // open.bigmodel.cn → API Keys
   DEFAULT_MODEL: 'glm-5.3',        // 想零成本就改回 'glm-4.7-flash'
   ```
2. **（强烈建议）部署旧版兜底中转**：`cd bilibili-toy && wrangler secret put ZHIPU_API_KEY && wrangler deploy`，
   把得到的地址填进隐藏入口「旧版引擎」并启用——这样直连被拦的环境也能用。
3. **上传 B站**：Toy 创作中心 → 新建 → 上传 `index.html` → 提审。

本地预览：`node preview.js` → http://localhost:8788 （未填 Key 时自动进入演示模式，回复为本地模拟）。

## 多端自适应

判定顺序：**鸿蒙 UA 形态字段 → 其他系统 UA → 分辨率兜底**，然后用该档位的参数（宽度、字号、内外边距、气泡上限、圆角）覆盖 CSS 变量。

| 档位 | 触发条件（短边） | 布局 |
|---|---|---|
| `phone-sm` 小屏手机 | 0–359 | 单列，13.5px，气泡 84% |
| `phone` 手机 | 360–520 | 单列，14px，气泡 80% |
| `fold` 折叠屏 | 521–760（或手机 UA + 接近方形） | 单列加宽 720px，14.5px |
| `tablet` 平板 | 761–1100 | 左侧栏 212px + 聊天区，15px |
| `desktop` 电脑 | 1101–1500 | 浮动卡片 1180px + 侧栏 256px，15px |
| `tv` 大屏/电视 | ≥1501 或 TV UA | 卡片 1480px + 侧栏 300px，17px |

**鸿蒙识别**：UA 含 `OpenHarmony` / `HarmonyOS` / `ArkWeb` 即判定为鸿蒙；再读第一个括号里的形态字段
`(Phone;` / `(Tablet;` / `(PC;` 区分手机、平板、2in1 电脑。HarmonyOS NEXT 的 UA 已不含 `Android`，
所以单独走这条分支，不会掉进安卓或桌面误判。

**UA 说不清时**（例如 B站 App 精简过的内嵌 UA）：读 `screen.width/height` 和 `devicePixelRatio`，
在档位表里找最接近的一个——区间内优先，区间外按「到边界的距离」最小者胜出。
拖动窗口、横竖屏切换会在 160–240ms 后重新判定并平滑换档。

桌面/平板的左侧栏会显示「当前环境」：系统、形态、分辨率、DPR、以及这次是 UA 识别还是分辨率匹配。

## 季节主题怎么改

- **想换哪个月算夏天**：改 `index.html` 里 `seasonNow()` 的月份区间（现在是 `5–8`，即 6–9 月）
- **想永久固定成某一季**：把 `CONFIG.THEME` 改成 `'winter'` 或 `'summer'`（默认 `'auto'`）
- **想调颜色**：所有品牌色集中在 CSS 顶部 `:root`（冬季）与 `html[data-season="summer"]`（夏季）两个变量块，改一处全站生效

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示「浏览器拦下了这次请求…」 | 直连被 CORS 拦截，属预期；走隐藏入口启用旧版中转 |
| 提示 401 | Key 填错或过期 |
| 提示 429 | 免费档限流 / 付费档并发限制，稍后再试 |
| 想换回纯免费 | `DEFAULT_MODEL: 'glm-4.7-flash'`，并在隐藏入口把投币门槛关掉即可 |

## API Key 与自动降级

- **仓库版不含 Key**：`CONFIG.API_KEY` 是空字符串。三种方式让它跑起来：
  1. 填自己的智谱 Key 到 `CONFIG.API_KEY`（推荐给私有部署）
  2. 让用户在「设置 → 我的 API Key」里自己填（只存本机）
  3. 用 `worker.js` 起一个中转，Key 放在 Worker 的环境变量里（不进前端）
- 免费档（GLM-4-Flash 等）开箱可用；**GLM-5.3 属付费档**，Key 余额不足时返回 1113
- 默认模型是免费的 **GLM-4-Flash**；GLM-5.3 仍挂「推荐」，选中后若余额不足（1113）
  或被限流（1305），会**自动切回免费模型重试**并弹提示，不会让用户对着报错发呆
- ⚠️ 安全提醒：Key 若写在前端代码里，**任何用户查看源码都能看到**。公开仓库请务必留空，
  用 Worker 中转或让用户自带 Key
- 修复：`isSupport` 在无原生桥的环境会永久挂起，导致「发送卡 3 秒」「退出只弹页面」。
  现在 `checkInputSafety` / `getContainerState` / `closeBrowser` 都改为直接调用 +
  短超时兜底，web 端 SDK 会立即抛 `unsupported`，不再卡流程
